# Planning documents
These are the vision, design and build plans written before the first line of code, in November 2026. They are kept as the record of what was planned and why.

Read them as history, not as a description of the finished game. The game changed as it was built, and the decisions that departed from these documents are in [docs/adr](../adr/README.md). For example, the plan offered "Play Solo" and "Play Together" as two entry points; they turned out to be the same game and were merged (ADR 0017).
