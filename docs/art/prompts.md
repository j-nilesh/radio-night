# Prompt pack

One prompt per image. Each starts with the shared skeleton and uses only details from `art-bible.md`. The pilot is the Tap Room and Ray. Do not make the others until the style is settled.

Skeleton: `Photograph, 1981, colour negative film look, warm tungsten light, visible film grain, shallow depth of field, small-town New Hampshire.`
Tail: `No text, no logos, no watermark, nothing modern.`
