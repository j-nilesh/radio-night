## Before recording
- Turn the voices and music on, close other tabs, and turn off notifications.
- Rehearse once, so the voiced questions are heard clearly the first time.
- Check the run is fresh (start a new investigation), so the opening plays.
- If a character's improvised answer differs from the script, keep it. Any reasonable answer works for the video.

## Upload checklist
- Public on YouTube, under 3:00, English.
- Description: one line about the game, the live URL and the repo URL.
- No outside music or logos. Don't show provider dashboards with account details.
